FIVE ALGORITHMS

Sorting Algorithms

Read the concept, follow the steps and explore the C program.

1. Bubble Sort

Compares adjacent elements and swaps them if they are in the wrong order.

Time: O(n²) average/worst

Space: O(1)

  1. Compare adjacent values.
  2. Swap if left is greater.
  3. Repeat until sorted.
View C program 
void bubbleSort(int a[], int n) {
    int i, j, temp;
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - i - 1; j++) {
            if (a[j] > a[j + 1]) {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
}

2. Selection Sort

Finds the smallest element in the unsorted part and puts it in the correct position.

Time: O(n²)

Space: O(1)

  1. Assume the first unsorted value is minimum.
  2. Search for a smaller value.
  3. Swap with the first unsorted value.
View C program 
void selectionSort(int a[], int n) {
    int i, j, min, temp;
    for (i = 0; i < n - 1; i++) {
        min = i;
        for (j = i + 1; j < n; j++) {
            if (a[j] < a[min])
                min = j;
        }
        temp = a[i];
        a[i] = a[min];
        a[min] = temp;
    }
}

3. Insertion Sort

Takes one element and inserts it into the correct position in the sorted part.

Time: O(n²) average/worst

Space: O(1)

  1. Keep the first element sorted.
  2. Take the next element as key.
  3. Shift larger elements right.
  4. Insert the key.
View C program 
void insertionSort(int a[], int n) {
    int i, j, key;
    for (i = 1; i < n; i++) {
        key = a[i];
        j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}

4. Merge Sort

Divides the array, sorts the smaller parts and merges them in order.

Time: O(n log n)

Space: O(n)

  1. Divide the array into halves.
  2. Keep dividing into smaller parts.
  3. Sort and merge the parts.
View C program 
void merge(int a[], int l, int m, int r) {
    int i = l, j = m + 1, k = 0;
    int temp[1000];

    while (i <= m && j <= r) {
        if (a[i] <= a[j])
            temp[k++] = a[i++];
        else
            temp[k++] = a[j++];
    }

    while (i <= m) temp[k++] = a[i++];
    while (j <= r) temp[k++] = a[j++];

    for (i = l, k = 0; i <= r; i++, k++)
        a[i] = temp[k];
}

void mergeSort(int a[], int l, int r) {
    if (l < r) {
        int m = l + (r - l) / 2;
        mergeSort(a, l, m);
        mergeSort(a, m + 1, r);
        merge(a, l, m, r);
    }
}

5. Quick Sort

Chooses a pivot, places smaller elements on its left and larger elements on its right, then sorts both parts.

Time: O(n log n) average

Space: O(log n) average

  1. Choose a pivot.
  2. Partition the array around it.
  3. Sort the left and right parts.
View C program 
int partition(int a[], int low, int high) {
    int pivot = a[high];
    int i = low - 1;

    for (int j = low; j < high; j++) {
        if (a[j] < pivot) {
            i++;
            int temp = a[i];
            a[i] = a[j];
            a[j] = temp;
        }
    }

    int temp = a[i + 1];
    a[i + 1] = a[high];
    a[high] = temp;

    return i + 1;
}

void quickSort(int a[], int low, int high) {
    if (low < high) {
        int p = partition(a, low, high);
        quickSort(a, low, p - 1);
        quickSort(a, p + 1, high);
    }
}

    Example 1: Insertion Sort

    Sort the array: 29, 10, 14, 37, 13

    Initial array:
29  10  14  37  13

Pass 1: Key = 10
Shift 29 right and insert 10.
10  29  14  37  13

Pass 2: Key = 14
Shift 29 right and insert 14.
10  14  29  37  13

Pass 3: Key = 37
37 is already in the correct position.
10  14  29  37  13

Pass 4: Key = 13
Shift 37, 29 and 14 right.
10  13  14  29  37

Final sorted array:
10  13  14  29  37

    Example 2: Merge Sort

    Sort the array: 89, 12, 34, 55, 60, 36, 52, 41, 78

    Step 1: Initial array

    89  12  34  55  60  36  52  41  78

    Step 2: Divide the array into two parts

    [89, 12, 34, 55]        [60, 36, 52, 41, 78]

    Step 3: Divide again

    [89, 12] [34, 55]       [60, 36] [52, 41, 78]

    Step 4: Divide into smaller parts

    [89] [12] [34] [55]     [60] [36] [52] [41, 78]

    Step 5: Divide until each part has one element

    [89] [12] [34] [55] [60] [36] [52] [41] [78]

    Step 6: Merge in ascending order

    [12, 89] [34, 55]       [36, 60] [41, 78]

    Step 7: Merge the smaller parts

    [12, 34, 55, 89]       [36, 41, 52, 60, 78]

    Step 8: Merge both halves

    [12, 34, 36, 41, 52, 55, 60, 78, 89]

    Final sorted array:

    12  34  36  41  52  55  60  78  89

    Example 3: Selection Sort

    Sort the array: 29, 10, 14, 37, 13

    Initial array:
29  10  14  37  13

Pass 1: Find minimum 10 and swap with 29.
10  29  14  37  13

Pass 2: Find minimum 13 in the remaining part.
10  13  14  37  29

Pass 3: Minimum is 14, so it stays in place.
10  13  14  37  29

Pass 4: Find 29 and swap with 37.
10  13  14  29  37

Final sorted array:
10  13  14  29  37

    Example 4: Quick Sort

    Sort the array: 6, 3, 8, 2, 5

    Initial array:
6  3  8  2  5

Step 1: Choose 5 as the pivot.
Step 2: Partition values around the pivot.
3  2  5  6  8

Step 3: Sort the left part [3, 2].
2  3  5  6  8

Step 4: The right part [6, 8] is already sorted.

Final sorted array:
2  3  5  6  8

    Example 5: Bubble Sort

    Sort the array: 5, 3, 8, 1

    Initial array:
5  3  8  1

Pass 1:
Compare 5 and 3 → swap.
3  5  8  1

Compare 5 and 8 → no swap.
3  5  8  1

Compare 8 and 1 → swap.
3  5  1  8

Pass 2:
Compare 3 and 5 → no swap.
Compare 5 and 1 → swap.
3  1  5  8

Pass 3:
Compare 3 and 1 → swap.
1  3  5  8

Final sorted array:
1  3  5  8
